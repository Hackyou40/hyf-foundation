## 1. Three new things I learned

I learned how to structure a simple page with semantic HTML elements such as headings, paragraphs, lists, and buttons. I learned how CSS media queries can change the layout for smaller screens, while custom fonts and CSS variables help create a consistent visual style. I also learned how JavaScript event listeners can make a button interactive by choosing a random color and changing the page background.

## 2. Changes I made to Copilot's suggestions

I changed the original portfolio hero section so that it clearly matched the assignment heading, “About Me,” instead of focusing mainly on selected work. I replaced the original call-to-action button with a “Surprise me” button and added three interests that fit my own profile. I also checked the generated result and corrected duplicate metadata and hero content that appeared after an automated edit.

## 3. Copilot as a generator vs. learning partner

Using Copilot to generate code means asking it to complete a task and accepting the result without necessarily understanding every choice. Using it as a learning partner means asking questions, reading the code, testing the behavior, and making decisions about what should be changed. A learning partner helps me build my own understanding, while a code generator can make me dependent on solutions I cannot explain or debug.

## 4. Three risks of relying too much on AI

One risk is that I may stop practicing problem-solving and struggle when I need to code without assistance. Another risk is accepting incorrect, insecure, or inaccessible code because I did not review and test the suggestion carefully. A third risk is producing work I cannot explain, which makes it harder to learn from mistakes and collaborate honestly with my HackYourFuture classmates.
